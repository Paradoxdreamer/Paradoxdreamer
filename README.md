### How I work

- Quiet interfaces. Explicit ownership.
- Secrets stay in `.env` / platform secrets — never in the repo.
- If a model or backend is unofficial or third-party, the UI says so.
- Prefer local-first and honest scoping over hype.
- Ship usable tools. Iterate in public.
